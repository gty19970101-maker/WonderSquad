# Save Data Boundary

## 系统目标

明确哪些数据可以保存在本地、哪些只属于当前权威会话，以及哪些未来功能需要后端，防止客户端本地数据被误用为多人玩法权威。

## 系统边界

负责：

- 本地设置数据分类。
- 存档格式版本、默认值和损坏恢复。
- 会话数据不得持久化的约束。
- 敏感数据和服务密钥边界。
- 未来云存档和 UGC 后端的引入条件。

不负责：

- 权威局内状态复制。
- 账号认证。
- 云存档。
- 玩家关卡上传。
- 商城、排行榜和经济数据。
- 具体文件读写实现。

## 核心流程

### 读取

```text
启动
→ 查找本地设置
→ 校验格式版本和字段
→ 可迁移则迁移
→ 损坏则保留诊断并回退默认
→ 应用到 UI、输入、音频和辅助功能
```

### 保存

```text
设置发生确认性变化
→ 生成当前格式数据
→ 校验范围
→ 安全写入临时目标
→ 原子替换正式文件
```

### 会话结束

```text
离开房间
→ 清理关卡、库存、物品、机关、状态和标记
→ 可选写入匿名测试摘要
→ 不写入权威世界快照
```

## 主要状态

- `NotLoaded`
- `Loading`
- `Loaded`
- `Dirty`
- `Saving`
- `Corrupted`
- `ResetToDefault`

数据类别：

- `LocalPreference`
- `LocalTutorialFlag`
- `OptionalTestTelemetry`
- `SessionAuthoritative`
- `FutureBackendData`

## 与其他系统的依赖

- `Player_System`：键位和摄像机设置。
- `Communication_System`：语音、静音、隐私和标记过滤。
- `Game_Loop`：启动与退出时机。
- `Level_Framework`：仅允许输出匿名测试摘要。
- `Network_Authority_Rules`：会话权威数据不得本地化。
- `Data_Driven_Design`：存档格式版本与稳定设置键。

## 联机同步要求

- 本地设置通常不需要同步。
- 显示名可发送到房间，但不构成可信身份。
- 当前房间内的单人静音、语音音量和标记过滤只影响本地。
- 参与者 PlayerId 是会话级标识，单人静音列表不跨会话持久化。
- 语言和 UI 设置不影响权威状态。
- 当前角色、库存、机关、状态、救援和变体不能从本地存档恢复到多人会话。
- 测试日志若分享必须经过明确流程，不自动上传。

## MVP范围

本地保存：

- 主音量、音乐、音效和语音音量。
- 分辨率、全屏、画质和帧率。
- 键位、手柄和镜头设置。
- 字幕、色觉、文字大小和语言。
- 为未来语音预留的全局开关、设备选择和音量；不保存具体参与者静音。
- 标记过滤和隐私设置。
- 是否看过基础教学。
- 存档格式版本。
- 可选匿名测试日志。

MVP 会话结束后不持久化：

- 玩家位置和角色运行状态。
- 团队库存。
- 道具实例。
- 制作结果。
- 机关状态。
- 临时状态和救援。
- 关卡变体和完成。

## 非MVP范围

- 正式账号。
- 云存档和跨设备同步。
- 长期基地和收藏。
- 玩家关卡草稿与发布。
- 商业化和经济数据。
- 排行榜和公会。
- 自动遥测上传。
- 加密凭据管理平台。

## 验收标准

- 首次启动产生有效默认设置。
- 损坏或未知版本不会阻止进入游戏。
- 写入中断不会破坏最后一个有效文件。
- 本地存档不含服务密钥、语音内容或权威会话快照。
- 修改本地文件不能改变多人库存、机关或完成结果。
- 静音和标记过滤只影响本地。
- 重新进入房间后不从旧会话 PlayerId 恢复单人静音。
- 退出房间后会话引用被清理。
- 存档版本升级具有明确迁移或重置策略。

## 风险与待确认事项

### 风险

- 调试数据误入正式存档。
- 未来长期进度与本地设置混在同一文件。
- 存储第三方语音设备标识造成平台兼容问题。
- 自动测试日志包含不必要个人信息。

### 待确认

- 本地文件格式采用 JSON 还是 Unity 可序列化格式；当前建议简单 JSON。
- 是否保存最近房间码；默认不建议长期保存。
- 测试日志的保留时长和用户同意方式。
- 未来角色外观是否属于本地偏好还是账号数据。
- 玩家关卡草稿未来的独立存储格式。
