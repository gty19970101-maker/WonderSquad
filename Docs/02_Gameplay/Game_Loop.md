# Game Loop

## 系统目标

定义 Wonder Squad 一局游戏从组队到结算的完整循环，使 2～4 名玩家在 10～20 分钟内持续经历“观察、沟通、选择方案、合作执行、失败恢复、完成目标”。

循环必须验证：

- 角色能力能改变解题过程。
- 不开语音仍能有效合作。
- 同一问题存在角色优势解法与通用替代解法。
- 普通失败不中断整关。
- 一张小地图形成独立闭环。

## 系统边界

本系统负责：

- 定义局外、局内和结算阶段。
- 定义核心节奏、阶段入口和退出条件。
- 规定各系统在循环中的参与时机。
- 规定一次冒险的完成、失败恢复和返回流程。

本系统不负责：

- 具体移动、采集、制作和机关规则。
- 网络传输实现。
- 账号、商城、长期成长或玩家关卡发布。
- 连续开放世界状态。

## 核心流程

```text
创建/加入房间
→ 选择角色
→ 加载独立关卡
→ 理解目标与交流方式
→ 探索并发现资源/路线/机关
→ 表达意图并形成分工
→ 使用能力、道具、制作或地形执行方案
→ 成功推进，或进入临时失败/救援
→ 完成三个核心机关
→ 完成最终目标
→ 结算
→ 返回关卡选择或离开房间
```

推荐时间预算：

| 环节 | 目标时长 |
|---|---:|
| 入场、目标和操作理解 | 1～2 分钟 |
| 探索与资源收集 | 3～5 分钟 |
| 三个合作机关 | 5～8 分钟 |
| 最终目标与结算 | 2～4 分钟 |

失败分支：

```text
操作失败
→ 主机确认失败结果
→ 搞笑状态/位置变化/局部重置
→ 玩家自救或队友救援
→ 返回当前问题
```

只有严重系统异常、全队主动选择或房间终止时才退出整局。

## 主要状态

### 会话阶段

- `Lobby`：组队与角色选择。
- `Loading`：加载关卡和权威内容。
- `WaitingForPlayers`：等待必要玩家准备。
- `Playing`：正常探索与解谜。
- `Completed`：主目标完成。
- `Result`：显示本局结果。
- `Leaving`：退出关卡或房间。

### 体验节奏状态

- 探索
- 发现问题
- 计划与沟通
- 执行方案
- 失败与救援
- 成功反馈

体验节奏状态用于设计和测试分析，不要求成为一个强制运行时状态机。

## 与其他系统的依赖

Game Loop 是产品流程定义，不作为 Gameplay 程序集。

运行时由 Level Orchestrator 实现该流程：

- 编译时依赖 Core/Contracts 与 Content。
- 订阅 Player、Puzzle、Status 和会话事件。
- 通过公开端口发出关卡开始、恢复和结束命令。
- 不要求任何领域模块反向依赖 Game Loop。

## 联机同步要求

- 主机决定关卡阶段、开始时间、完成和结算。
- 所有客户端看到一致的主要目标和机关完成状态。
- 角色选择、玩家准备和关卡变体在开局前确认。
- 失败、救援和局部恢复不能由单个客户端自行宣布。
- 结算只接受主机确认的时长、解法、失败和救援记录。
- 客户端断线或主机退出按关卡会话规则处理；MVP 不要求主机迁移。

## MVP范围

- 一张《沉睡森林》独立小地图。
- 2～4 人。
- 10～20 分钟。
- 三个合作机关。
- 角色能力、非语音交流、多解法、欢乐失败和救援全部进入循环。
- 结算至少展示完成、用时和基础体验反馈。
- 完成后返回关卡选择或房间，不无缝进入开放世界。

## 非MVP范围

- 多关卡连续剧情流程。
- 开放世界探索循环。
- 商业化、排行榜、公会和复杂基地循环。
- 长期装备、等级和重复刷取循环。
- 玩家关卡发布、推荐和审核循环。
- 失败后的复杂投票与主机迁移。

## 验收标准

- 2、3、4 人均能从房间完整走到结算。
- 大多数有效测试局为 10～20 分钟。
- 全队不开麦仍能完成。
- 至少一个问题在不同测试中使用两种以上方案。
- 缺少任一特定角色的代表阵容仍能通关。
- 四角色可重复选择的 65 个无序 2～4 人组合均通过声明通路结构校验。
- 普通失败后无需重载整关。
- 玩家在探索、沟通、执行和救援阶段都没有长期无事可做。
- 结束条件对所有客户端一致，且只能触发一次。

## 风险与待确认事项

### 风险

- 系统数量增加导致单局超过 20 分钟。
- 交流提示过多破坏探索感。
- 替代解法过慢，形成事实上的角色硬锁。
- 欢乐失败出现过于频繁，打断核心节奏。

### 待确认

- MVP 结算页具体展示哪些统计。
- 关卡开始由主机手动触发还是全员准备后自动触发。
- 完成后保持房间还是解散房间。
- MVP 后续语音 SDK 的评估时间；首个对外测试构建不包含语音。
