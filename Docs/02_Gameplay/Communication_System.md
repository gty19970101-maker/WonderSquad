# Communication System

## 系统目标

同时支持语音和游戏内动作交流，并保证不开语音的玩家也能理解目标、表达计划、协调机关和请求救援。

MVP 的强制能力是非语音交流；语音是独立、可选的便利层。

## 系统边界

负责：

- 场景标记。
- 快捷意图。
- 表情与角色动作。
- 求救表达。
- 标记生命周期、类型、优先级、频率和过滤。
- 可选语音服务适配、静音和设备状态。
- 交流的世界、UI 和角色表现。

不负责：

- 使用交流内容判定谜题完成。
- 语音识别。
- 自行完成交互或救援。
- 复杂自由文本聊天。
- 长期聊天记录和内容存档。

## 核心流程

### 场景标记

```text
玩家选择标记类型
→ 指定世界位置或目标
→ 客户端提交 MarkerRequest
→ 主机校验位置、频率、数量和权限
→ 创建 MarkerSnapshot
→ 所有客户端显示
→ 到期、发送者移除或场景卸载时销毁
```

### 快捷意图

```text
打开动作轮盘
→ 选择语义键
→ 播放角色动作
→ 显示短文本/图标/声音
→ 必要时同步短暂事件
```

### 求救

求救由 `Status_And_Failure_System` 的权威状态驱动。Communication 只负责让队友看到位置、状态和建议操作。

### 语音

以下流程属于 MVP 验证通过后的产品版本，第一阶段不执行：

```text
加入游戏房间
→ 可选加入对应语音房间
→ 本地处理权限与输入设备
→ 语音服务传输
→ 本地静音和音量
→ 离开游戏房间时离开语音房间
```

## 主要状态

### 标记

- `Requested`
- `Active`
- `Expired`
- `Removed`
- `Rejected`

### 快捷意图

- `Idle`
- `WheelOpen`
- `Selected`
- `Playing`

### 语音本地状态

- `Unavailable`
- `PermissionRequired`
- `Connecting`
- `Connected`
- `Muted`
- `Error`

语音状态不属于关卡权威状态。

## 与其他系统的依赖

编译时依赖：

- `Core/Contracts`：MarkerCommand、QuickIntent、Emote、HelpRequested 和只读目标信息。

通过端口或事件协作：

- 使用 `IPlayerQuery` 获取发送者位置。
- 消费 Status 发布的 HelpRequested。
- 消费 Puzzle 与 Level 的只读快照用于表现，不参与条件判定。
- 观察者增强以 AbilityApplied 事件或 MarkerModifier 输入，不引用 Ability 实现。
- UI 与小地图消费 MarkerSnapshot。
- Save 端口提供本地过滤；当前会话单人静音不持久化。
- Network Adapter 传输标记和快捷意图。

## 联机同步要求

- 主机校验场景标记位置、类型、频率、数量和有效期。
- 同步语义 ID，不同步本地化字符串。
- 表情和庆祝可使用短暂事件。
- 求救必须可从持续状态重建，不能只依赖一次 RPC。
- 本地隐藏标记或静音不改变其他玩家状态。
- 语音音频不通过 Fusion 玩法通道。
- 语音内容不记录、不存档、不参与完成判定。
- 玩家离开时移除或缩短其标记生命周期。

## MVP范围

- 场景标记：地点、资源、机关、路线、危险、帮助。
- 标记同时提供世界内表现和小地图表现。
- 小地图使用 LevelDefinition 的固定地图边界，将世界坐标映射到轻量俯视图。
- 小地图只显示队友、主要目标和有效标记，不实现战争迷雾、路径规划或动态地图生成。
- 快捷意图：来这里、等待、我来、你来、需要帮助、资源不足、完成了。
- 基础角色动作或表情。
- 求救状态表现。
- 键鼠和手柄轮盘。
- 图标、形状、短文本和音效组合反馈。
- 标记频率和数量限制。
- 本地隐藏和过滤。
- 全队不开麦完整通关测试。
- 只保留语音适配接口；第一阶段不集成语音 SDK。

## 非MVP范围

- 自由文本聊天。
- 语音识别与翻译。
- 语音内容存档。
- 空间语音的复杂遮挡模拟。
- 社区频道。
- 复杂举报审核后台。
- 玩家自定义表情包。

## 验收标准

- 常用意图可在一到两次操作内表达。
- 全队关闭语音仍能完成《沉睡森林》。
- 同步机关不要求毫秒级语音倒数。
- 资源不足、等待、集合和求救均有非语音表达。
- 标记在世界中清晰，且不会无限累积或刷屏。
- 手柄玩家不需要快速输入文字。
- 重要信息不只依赖颜色或声音。
- 麦克风权限拒绝不阻止进入或通关。
- Puzzle 不读取语音或快捷消息作为完成条件。

## 风险与待确认事项

### 风险

- 标记和交互提示重叠。
- 快捷意图数量过多导致选择困难。
- 标记被恶意刷屏。
- 观察者的信息优势削弱所有玩家的基础沟通能力。
- 语音 SDK 带来权限、平台、费用和合规工作。

### 待确认

- MVP 后续采用哪个基础队伍语音 SDK。
- 小地图美术采用固定俯视轮廓还是简化拓扑轮廓；坐标映射固定使用关卡边界。
- 标记默认数量、持续时间和冷却。
- 是否允许只对特定队友发送标记；MVP 建议全队共享。
- 需要支持的首发语言和本地化键集合。
