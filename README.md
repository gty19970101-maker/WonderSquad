# Wonder Squad

Wonder Squad 是一款面向 2～4 人合作的环境解谜游戏。当前仓库包含项目设计文档与 Unity 客户端工程。

## Unity 版本基线

项目唯一正式 Unity Editor 版本为 **Unity `6000.3.21f1`（Unity 6.3 LTS）**。

- Unity 工程目录：`Client/`
- 不得使用其他 Unity 版本保存项目资源。
- Unity、URP 或官方包版本变更必须作为独立迁移任务完成影响分析、Review 和 P0 回归。
- 当前客户端打开与验证步骤参见 `Client/README.md`。

开发流程与约束参见 `CONTRIBUTING.md` 和 `Docs/00_Project/Development_Workflow.md`。
